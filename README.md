# Мария / Jarvis 6.37

Персональный помощник для Android: голосовые команды, поиск фотографий и документов, чтение текста на экране, календарь и действия через специальные возможности.

[Скачать APK и полный проект](https://github.com/Alex-bc21/maria-android/releases/tag/v6.37).

Предварительная версия. Android 10+ (API 29), ARM64. Разработка и прежние проверки проводились на Samsung Galaxy S25; совместимость с другими устройствами не подтверждена. Сборка подписана отладочным сертификатом. API-ключи и аккаунты настраиваются пользователем, в APK их нет. OpenAI требует собственного подключения и может быть платным. Для локальной языковой модели используется отдельная установка через install-model.ps1.

## Файлы

- `Maria-6.37.apk` — установочный файл.
- `Maria-6.37-source.zip` — полный снимок проекта с библиотеками и моделями, из которого собран APK.
- `Maria-6.37-code.zip` — компактный архив кода и документации без крупных бинарных компонентов; для сборки используйте полный архив.
- `SHA256SUMS.txt` — контрольные суммы.

## Сборка

На Windows нужны PowerShell 7, JDK 17+ и Android SDK: build-tools 36.0.0, platforms android-35 и android-37.0. В корне полного архива:

```powershell
./build.ps1 -Sdk <Android-SDK> -Jdk <JDK> -Keystore <ваш-debug.keystore> -Destination ./build
```

По умолчанию используется локальный `.android/debug.keystore`. Ключ подписи не включён; своя подпись не позволит обновить установленный официальный APK поверх прежнего.
