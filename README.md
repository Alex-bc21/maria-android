Помощник для Android 10+: команды телефона, поиск файлов, чтение доступного текста на экране, календарь и напоминания. Марка телефона не ограничена.

## Какую версию установить

- **Maria-6.39-universal.apk** — рекомендуемая облегчённая версия, около 4,4 МБ. Не содержит нативных библиотек, подходит для ARM, ARM64 и x86/x86_64. Использует установленный голос Android. Сохраняет текстовые команды, поиск по названиям файлов, чтение доступного текста интерфейса и пользовательское подключение OpenAI. Без сервиса распознавания команды можно печатать.
- **Maria-6.39-full-arm64.apk** — около 171 МБ, для ARM64 с достаточным запасом памяти. Дополнительно содержит локальный голос, OCR и поиск фото/видео по содержимому. Qwen устанавливается отдельно; для неё проверяется запас памяти не менее 1,5 ГиБ сверх системного порога. Это предварительная проверка, а не гарантия отсутствия нехватки памяти.

Оба варианта имеют один пакет, versionCode 56 и прежний сертификат подписи. Устанавливайте один вариант; его можно сменить установкой поверх без удаления приложения. Подпись пока отладочная, как у предыдущего релиза.

Google Фото необязателен: снимки выбираются через системный интерфейс. Для Google Диска/Задач/Карт нужны соответствующие приложения и аккаунты; их отсутствие не мешает основным локальным командам. Русский голос и распознавание зависят от установленных служб Android. OpenAI подключается пользователем и может быть платным.

Для личных данных нужна блокировка экрана телефона. Чтение чужих приложений требует разрешённых специальных возможностей и доступного текста. Системная панель ассистента доступна на Android 12+, способ вызова зависит от оболочки. Автоматическое переключение GPS пока проверено только для известного интерфейса Samsung; на других оболочках открываются настройки и может потребоваться ручное действие. Мария не нажимает неизвестные переключатели наугад.

## Сборка из исходников

Полный проект: `Maria-6.39-source.zip`. Компактный `code.zip` содержит код и тесты, но не все бинарные зависимости/модели; для сборки используйте полный архив.

Нужны JDK 17+, Android SDK Platform 37, Build Tools 36.0.0 и сеть для Gradle. Gradle Wrapper 9.5.0 и AGP 9.3.1 закреплены в проекте. compileSdk 37 нужен для метаданных ассистента; минимальный Android — 10/API29, targetSdk — 35. Core library desugaring адаптирует новые функции Java для старых Android.

```powershell
./build.ps1 -Sdk <Android-SDK> -Jdk <JDK> -Keystore <debug.keystore> -Variant Both
```

По умолчанию собирается Portable. `-Variant Full` включает локальные модели. Выход: `build/Maria-portable.apk`, `build/Maria-full.apk`; `Jarvis-Search.apk` — копия первого выбранного варианта для прежних локальных сценариев. Ключ подписи в исходники не входит; своя подпись не позволит обновить официальный APK поверх существующего.

На других ОС задайте ANDROID_HOME и JAVA_HOME, выполните `./gradlew assemblePortableRelease assembleFullRelease`. Путь к своему debug-keystore можно передать через `-PmariaKeystore=...`.

Проверки: `./gradlew lintPortableRelease lintFullRelease assemblePortableReleaseAndroidTest`. Инструментальные тесты рассчитаны на отдельный разблокированный AOSP-эмулятор с тестовым PIN, без Google-сервисов. Никогда не запускайте настройку тестового эмулятора на личном телефоне.
